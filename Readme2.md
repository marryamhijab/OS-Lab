xv6 Process Manager

Extending the xv6-riscv kernel (MIT's teaching operating system) by adding five new modules.

Name: Marryam Hijab Course: Operating System

Modules Added
Process Monitoring: ps lists running processes with PID, state, memory and priority
Syscall Tracing: trace prints the system calls a program makes
System Information: sysinfo shows free memory and number of processes
Priority Scheduler: nice sets process priority so important processes get more CPU
Lazy Memory Manager: memory is allocated only when a program actually uses it
